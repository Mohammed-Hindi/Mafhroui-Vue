# هوية لوحات منصة مسار (النهج المعتمد — 2026-10-15)

المرجع المنفَّذ: **لوحة الطالب كاملة** و**الصفحة الرئيسية للإدارة العامة** (`/committee` بحساب السوبر أدمن).
أي صفحة جديدة أو معدّلة في أي لوحة تتبع هذا الملف. هو يكمّل `UCAS_DESIGN_SYSTEM.md` ويتقدّم عليه في اللوحات حيث يختلفان
(السماوي القديم والزوايا الحادة 4px لم يعودا مستخدمين داخل اللوحات).

كل الأنماط في `src/styles/ucas-portal.css` تحت الصنف **`.sa-skin`** (يُضاف في `DashboardLayout` لكل أدوار البوابة).
البوب اب والقوائم المنسدلة تُنقل إلى `<body>` فتُربط بـ `:root[data-brand="ucas"]` بدل `.sa-skin`.
**لا ألوان hex جديدة في القوالب** — استخدم الأصناف والمتغيرات أدناه.

## 1) الألوان والتدرّجات

| الاسم | القيمة | الاستخدام |
|---|---|---|
| أزرق الهوية | `var(--ucas-blue)` = `#005BAA` | العناوين، القيم، الروابط، اللون الأساسي (primary) |
| أخضر الهوية | `var(--ucas-green)` = `#62BB46` | التسميات (labels)، عناوين المجموعات، المكتمل |
| التدرّج الكامل | `linear-gradient(270deg, #62BB46 0%, #50A16E 30%, #0E699C 65%, #025DA9 100%)` | التوب بار، رؤوس البوب اب، رؤوس البطاقات المميزة، البانر، شريط الملخّص |
| تدرّج الأزرار | `linear-gradient(270deg, #62BB46, #0E699C 55%, #025DA9)` | الأزرار الأساسية، رأس الجداول |
| خط التدرّج | `linear-gradient(270deg, #62BB46, #005BAA)` | الخط تحت العناوين، شريط جانبي، خط التقدّم |
| الخلفية الخفيفة | `linear-gradient(270deg, rgba(98,187,70,.1), rgba(0,91,170,.05))` | رؤوس الأقسام، العنصر المختار، صناديق المعلومات |
| كحلي التبويبات | `#0B2545` | خلفية كبسولة التبويبات والشعب |

- **اللون الأساسي داخل اللوحات = أزرق الهوية** (متغيرات `--color-primary-*` و`--portal-cyan` مُعاد تعريفها تحت `.sa-skin`). لا سماوي `#35B8E0` ولا أخضر الأزرار القديم `#10C469` للأزرار.
- **ألوان الحالة** (لا تُستخدم لغير الحالة، وتأتي دائمًا مع نص):
  انتظار رمادي `#98A6AD` · تنفيذ أزرق `#35B8E0→#0E699C` · مراجعة برتقالي `#F9C851→#F89E32` · مكتمل أخضر `#62BB46→#0E699C` · خطأ أحمر `#FF5B5B`.

## 2) الأشكال والحركة

- **الزوايا:** بطاقات وأقسام `16–18px`، عناصر داخلية `12–14px`، أزرار وحقول وتبويبات وشارات **كبسولة `999px`**، صور شخصية وأيقونات دوائر.
- **الظل:** بطاقة `0 10px 30px rgba(4,40,80,.08)` — بلا حدود (border: 0). عنصر داخلي: `0 0 0 1px color-mix(in srgb, var(--ucas-blue) 12%, transparent)`.
- **الحركة:** دخول هادئ `saFadeUp .4–.5s` (صعود 6px + ظهور)، والقوائم بتأخير متدرّج. لا قفز ولا تكبير ولا دوران (عدا زر إغلاق السايد بار 90° عند المرور). كل حركة تُلغى تحت `prefers-reduced-motion`.
- **الأقسام الكبيرة (اللاندج):** GSAP عبر `src/composables/useScrollMotion.js` (`useScrollMotion` + `titleIn` + `iconParts`).

## 3) الإطار العام (موحّد لكل اللوحات — لا يُعدَّل لكل صفحة)

- **التوب بار + رأس السايد بار:** شريط واحد بالتدرّج الكامل ممتد على عرض الشاشة، خط عمودي أبيض شفاف بينهما.
  اسم الصفحة كبسولة بيضاء بنص أزرق ونقطة خضراء. الأيقونات والاسم بالأبيض.
- **السايد بار:** أبيض. عناوين المجموعات خضراء قابلة للطي. العنصر النشط: خلفية تدرّج خفيفة + أيقونة خضراء + نص أزرق عريض + شريط تدرّج جانبي.
  الطالب: مجموعة «أدوات الطالب» ثم باقي الصفحات بلا عنوان.
- **الجوال/الآيباد:** زر الإغلاق بعد اسم المنصة — دائرة بيضاء بعلامة × متدرّجة.
- **الفوتر:** نفس تدرّج التوب بار، سطر واحد في الوسط: «{السنة} © جميع الحقوق محفوظة لـ منصة مسار في الكلية الجامعية للعلوم التطبيقية».

## 5) أنماط صفحات مرجعية

- **رئيسية الإدارة العامة:** بانر بالتدرّج + مطر البيانات (`DataRain`) + شعار مسار (`MasarWordmark`) + ترحيب + أرقام بيضاء (`CountUp`)؛
  ثم بطاقات الجداول؛ «حالة المهام» = رقم رئيسي + شريط مقسّم بالحالات + مفتاح بالعدد والنسبة + قائمة تقدّم مجموعات تمرَّر داخليًا + مربعات ملخّص.
- **لوحة المهام (`TaskBoard`):** أعمدة زوايا 16 بخط حالة تحت الرأس ونقطة ملوّنة وعدد بدائرة متدرّجة؛ البطاقة بشريط حالة جانبي، لا تنضغط (`flex-shrink: 0`)؛
  الضغط يفتح بوب اب بالتفاصيل كاملة (بيانات، وصف، ملفات، ملاحظات، سجل حركة كخط زمني).
- **قائمة + تفاصيل** (الإعلانات، الشكاوى): العمودان بنفس الطول (`clamp(460px, 100vh-300px, 820px)`) ويمرَّران داخليًا؛ العنصر المختار بخلفية تدرّج وشريط أخضر.
- **بطاقتان متجاورتان** (تغيير كلمة المرور): نفس الرأس المتدرّج ونفس الطول، والمحتوى يملأ الطول بلا فراغ.
- **المساعد الآلي:** رأس متدرّج بأيقونة في دائرة بيضاء، خلفية بشبكة نقاط، شعار مسار + «منصة إدارة مشاريع التخرج» قبل المحادثة، فقاعات زوايا 18 (المستخدم بالتدرّج).
- **البوب اب:** رأس بالتدرّج وشبكة نقاط، زر إغلاق دائري، خلفية معتمة كحلية، دخول بصعود ناعم، أقسام داخلية ببطاقات وعناوين بخط تدرّج.

## 6) قواعد العمل

- طبّق الأصناف الموجودة أولًا؛ أي نمط جديد يُضاف تحت `.sa-skin` في `ucas-portal.css` وبنفس القيم أعلاه.
- راجع كل صفحة بلقطة شاشة على 1440 و1024 و390، وتأكد: لا سكرول أفقي، لا عناصر مقصوصة أو متداخلة، الأعمدة/البطاقات المتجاورة متساوية.
- **الفرونت فقط** — لا تعديل على الباك (`Mashroui`).
